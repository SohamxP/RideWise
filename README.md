# RideWise

RideWise is an Android ride-decision application being upgraded from fixed simulated fare formulas to a Python ML-backed prediction system.

- Android client: Java, Firebase, Google Places, Retrofit
- Prediction API: Python, FastAPI
- ML: XGBoost + scikit-learn preprocessing
- Training data: public NYC TLC High Volume FHV trip records

See `backend/README.md` for the model/API workflow.
